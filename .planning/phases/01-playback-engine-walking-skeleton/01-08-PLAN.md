# Phase 1 Plan 08: A debug panel that shows what the engine is doing (debug and profile builds only)

## Phase Goal

ROADMAP Phase 1 Goal (verbatim): "A user on a physical Android phone can start a Bulgarian station and it keeps playing on its own through screen-off, background, calls, headphone changes, network switches and dead primary streams. The live edge, correct Cyrillic now-playing and media controls all work." (This line is not in user-story form; see 01-01-PLAN.md "Phase Goal".)

<objective>
Give the owner an in-app view of the engine for device verification (D-07). It shows the state-machine state, the stream URL, format and `streams[]` index, time-to-audio, the reconnect attempt and backoff delay, the recent-event log and the first-launch date. It also has a switcher that plays any `streams[]` entry, which is how SC1 "every streams[] index plays" gets verified (RESEARCH Test Map, SC1 row). All of it is present only in debug and profile builds.

Purpose: makes the SC1 and SC3 owner checks observable (PLAY-07 recovery timing, PLAY-08 rotation, APP-06 first-launch evidence) without adb.
Output: DebugPanel, diagnosticsProvider, HomeScreen wiring and widget tests.
</objective>

| debug build → release build | Diagnostics tooling must not cross into the shipped app |
| engine diagnostics → storage/network | Listening activity must stay in memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Information Disclosure | DebugPanel in release builds | medium | mitigate | `showDebugTools = !kReleaseMode` (a const, tree-shaken), a widget test with the flag off, and the import-locality grep gate. |
| T-08-02 | Information Disclosure (privacy) | diagnostics event log | low | mitigate | The ring buffer (50) lives in engine memory only; the panel only renders it and has no export, no file write and no network call (prohibition below). PLAT-06's CI deny-list (01-02) blocks tracking SDKs. |

</threat_model>
