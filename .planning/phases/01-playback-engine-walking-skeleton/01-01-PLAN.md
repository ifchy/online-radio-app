# Phase 1 Plan 01: Walking skeleton (tracer) — tap БГ Радио, hear it with the screen off

## Phase Goal

ROADMAP Phase 1 Goal (verbatim): "A user on a physical Android phone can start a Bulgarian station and it keeps playing on its own through screen-off, background, calls, headphone changes, network switches and dead primary streams. The live edge, correct Cyrillic now-playing and media controls all work."

> MVP note: this Goal line is not in user-story form ("As a …, I want to …, so that …"). The planner does not invent a story. Run `/gsd mvp-phase 1` if you want the Goal rewritten as a user story; the plans do not change.

<objective>

<assumption_delta_decision>
Signal: the assumption-delta probe fired (`pluralization`, term "fallback": "If the primary stream is dead, a fallback stream plays").
- **Primary noun:** `Station.streams[]`, the ordered list of `StationStream` (primary first, then fallbacks), per D-04.
- **Decision: promote.** `Station` has **no** singular stream-URL field. The engine always plays `station.streams[i]`. The index being played is engine state (`PlaybackStatus.streamIndex`), not a station field. The Phase 2 catalogue schema (CAT-02: "prioritised `streams[]`") uses the same shape, so nothing has to be migrated later.
- **Rationale:** a station with several official endpoints is the normal case (D-03/D-04). A singular `url` alongside `streams[]` would let later code bypass rotation (PLAY-08).
- **Invariant tests (accepted):** this plan creates the empty-`streams` rejection in `Station` and the tracer test checks that the loaded URL is `station.streams.first.url`. Plan 01-05 adds `test/features/catalog/station_test.dart`, which rejects a `Station` with an empty `streams` list. Plan 01-09 adds the rotation test: stream 1 plays when stream 0 fails.
</assumption_delta_decision>

       - Playing → ready, playing true
