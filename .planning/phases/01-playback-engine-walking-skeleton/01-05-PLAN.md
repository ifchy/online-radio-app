# Phase 1 Plan 05: Correct Cyrillic "now playing" that never goes stale

## Phase Goal

ROADMAP Phase 1 Goal (verbatim): "A user on a physical Android phone can start a Bulgarian station and it keeps playing on its own through screen-off, background, calls, headphone changes, network switches and dead primary streams. The live edge, correct Cyrillic now-playing and media controls all work." (This line is not in user-story form; see 01-01-PLAN.md "Phase Goal".)

<objective>
Show ICY "now playing" artist/title on the mini-player, the notification and the lock screen, with windows-1251 repair, sanitising, junk filtering, and a guaranteed clear when the station changes.

Purpose: STRM-05, and the PLAY-02 "now playing" clause. Media3's IcyDecoder falls back to ISO-8859-1, so cp1251 titles arrive as mojibake. The native ICY state also survives a load, so without a guard the previous station's title can show under the new one (PITFALLS Pitfall 6; RESEARCH Pattern 5, Pitfall E).
Output: the cp1251 table and repair, the sanitiser, the parser, `NowPlaying`, the handler/engine/provider/mini-player wiring, and golden tests.
</objective>
