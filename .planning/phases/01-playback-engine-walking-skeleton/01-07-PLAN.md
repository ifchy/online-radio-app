# Phase 1 Plan 07: The notification speaks the listener's language, and the first launch is remembered

## Phase Goal

ROADMAP Phase 1 Goal (verbatim): "A user on a physical Android phone can start a Bulgarian station and it keeps playing on its own through screen-off, background, calls, headphone changes, network switches and dead primary streams. The live edge, correct Cyrillic now-playing and media controls all work." (This line is not in user-story form; see 01-01-PLAN.md "Phase Goal".)

<objective>
Bring the notification and lock screen up to the mini-player: the same localised state text under the station name (D-09), the eRadioto small icon and a localised channel name. Lock down the media-session contract with unit tests: the full FGS table (all eight states) and every media-ID form. Record the first-launch date once (APP-06).

Purpose: PLAY-02 (station and state on the notification and lock screen), APP-07 (fixed control order, notification shown without a runtime permission), APP-06, and the battery rule behind PLAY-01 (no FGS in Paused, Error or Idle), proven row by row.
Output: `EngineStrings`, the subtitle mapping, the notification icon, bootstrap wiring, `SettingsRepository`, and the mapping, media-ID and settings tests.
</objective>
